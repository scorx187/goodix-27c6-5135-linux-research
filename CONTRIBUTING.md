# Contributing

Contributions are welcome, especially from owners of `27c6:5135` hardware.

Please include:

- exact VID:PID,
- firmware version,
- chip ID if safely readable,
- Windows driver version if dual-booting,
- whether the device still works in Windows,
- read-only command results or redacted traces.

Please **do not** attach:

- factory PSKs,
- biometric images/templates,
- Windows Hello databases,
- private calibration files unless carefully redacted,
- proprietary driver binaries.

When proposing a write or provisioning step, document why it is safe for the exact firmware/profile and what recovery path exists.
